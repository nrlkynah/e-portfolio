Career Exploration

Chosen Career Role: SOC Analyst

A Security Operations Center (SOC) Analyst is responsible for monitoring and analyzing security events within an organization’s systems and networks. SOC Analysts help identify cyber threats, investigate suspicious activities and respond to security incidents before they become serious attacks.

  • Monitor network traffic and security alerts.
  • Identify malware, phishing and suspicious activities.
  • Analyze logs and investigate security incidents.
  • Use cybersecurity tools such as Wireshark and SIEM platforms.
  • Support incident response and system protection activities.
  • Help organizations improve cybersecurity awareness and security practices.
